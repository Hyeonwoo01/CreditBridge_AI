# CreditBridge AI — 공개 데모

강의계획서를 분석해 편입 대학의 어떤 과목으로 학점이 인정될지 원문 근거와 함께 추천하고, 학과 교수가 최종 판정하는 편입 학점 심사 플랫폼의 **예시용 데모**입니다.

- 로그인 화면의 "데모 계정으로 둘러보기" 버튼으로 학생·학사처 심사관·학과 교수·기관 관리자 화면을 볼 수 있어요. 비밀번호는 모두 `demo1234`.
- AI 분석은 Claude 대신 **미리 정해 둔 예시 AI**가 해요. 새 강의계획서를 올리면 내용과 상관없이 예시 규칙으로 결과가 나와요.
- 서버가 다시 시작하면(잠들었다 깨어날 때 포함) 처음 상태로 돌아가요. 실제 개인정보나 자료는 올리지 마세요.
- 비밀번호 변경·초기화, 계정 비활성화는 데모에서 막혀 있어요.

소스와 운영 배포 방법은 원본 저장소를 보세요: https://github.com/Hyeonwoo01/CreditBridge_AI
