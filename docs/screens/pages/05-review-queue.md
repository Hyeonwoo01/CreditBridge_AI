## 필터 규칙

| 필터 | 포함 조건 |
| --- | --- |
| 전체 | 판정을 기다리는 모든 건 |
| 고신뢰 / 저신뢰 / 정보 부족 | 겹치지 않는 구분: 추천이 정보 부족이면 정보 부족, 아니면 신뢰도 상(high)은 고신뢰, 중·하는 저신뢰 |
| 일관성 경보 | 같은 출신 과목·같은 대상 과목·강의계획서 유사도 80% 이상(decisions.SIMILARITY_MIN)의 과거 판정이 AI 추천과 결과가 다른 건. 다른 탭과 겹칠 수 있음 |
| 학과 | 후보 과목의 학과 (후보 없으면 "미분류") |
| 정렬 | 접수일순(기본) · 커버리지 높은 순 · 학과순 (URL 파라미터) |
