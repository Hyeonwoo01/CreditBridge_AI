| 항목 | 내용 |
| --- | --- |
| URL | `GET /student/requests/{id}?show=all\|approved\|supplement\|review&tuition=&degree=` (`show`가 목록에 없는 값이면 422) |
| 역할 | 학생 (본인 요청만, 남의 요청은 403) |

### 심사 진행 현황 (progress-stepper)

| 단계 | 완료 조건 | 보조 문구 |
| --- | --- | --- |
| ① 서류 접수 | 강의계획서가 1건 이상 | "강의계획서 N건" / "강의계획서를 올려 주세요" |
| ② AI 구조화·근거 추출 | 분석 중인 과목이 없음 | "과목별 개념·근거 구절 추출 완료" / "분석 중이에요" |
| ③ 학과 교수 심사 | 요청 상태가 판정 완료 | 제출 후 "N / M 과목 판정" + 진행 막대 / 제출 전 "학사처에 심사를 요청하면 시작돼요" |
| ④ 최종 확정 | 요청 상태가 판정 완료 | "모든 과목 판정 완료" / "교수 판정이 끝나면 확정돼요" |

- 단계 원 24px: 완료는 `{colors.primary}` 채움 + 체크, 진행 중(완료되지 않은 첫 단계, 단 ③은 제출 후에만)은 2px primary 테두리 + 번호 + "진행 중", 대기는 헤어라인 테두리 + muted 번호.
- 단계 사이 세로선은 완료 구간만 `{colors.primary}`, 나머지 `{colors.hairline}`.

## 상태

| 상태 | 표시 |
| --- | --- |
| 초안(draft) | 추가 업로드 버튼, 업로드 2칸, [학사처에 심사 요청] 표시. 히어로 캡션 "제출 전" |
| 제출됨 / 판정 완료 | 업로드 칸 숨김. 히어로 캡션 "학사처 심사 중" / "판정 완료" |
| 과목 없음 | "강의계획서를 올리면 과목별 결과가 여기에 나와요." |
| 필터 결과 없음 | "이 조건에 해당하는 과목이 없어요." |
| 같은 파일 다시 올림 | 플래시 "이미 올린 문서라 저장된 분석 결과를 그대로 보여드려요" |
| 업로드 거부 | 플래시(빨강): 빈 파일, 지원하지 않는 형식(DOCX 등은 PDF로), 암호 PDF, 20MB 초과 |

## 반응형

- `lg`(1024px) 미만: 오른쪽 열(진행 현황·계산 조건·삭제 요청)이 과목 목록 아래로 내려간다.
- `sm`(640px) 미만: 메트릭 카드 3장이 세로로 쌓이고, 핵심 문장은 32px로 줄어 줄바꿈된다. 필터 칩은 두 줄로 감싼다.

## 표시하지 않는 것

- 판정 확률(%) — 커버리지, 3단계 추천, 신뢰도만 보여 준다.
- 상담 담당자 연락처 카드 — 실제 담당자 데이터가 없어 넣지 않았다.
