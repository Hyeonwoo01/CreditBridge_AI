# P17 오류

| 항목 | 내용 |
| --- | --- |
| URL | 모든 화면에서 오류 시 같은 주소로 표시 |
| 역할 | 전체 |
| 템플릿 | `error.html` |
| 기능 | 권한 없음(403), 없음(404), 업무 오류(400) 안내. API 경로(`/api/*`)는 JSON `{"detail": ...}` |

## 위치

```
[global-nav: 역할 메뉴·숫자 배지 없음 (이전 화면으로 / 처음으로 링크로 돌아감)]
        ┌ 파치먼트 박스 (520px, 가운데) ┐
        │ 오류 메시지 (20px/600)        │
        │ 이전 화면으로 · 처음으로       │
        └──────────────────────────────┘
[footer]
```

## 컴포넌트

| 영역 | 컴포넌트 | 내용 | 토큰 |
| --- | --- | --- | --- |
| 박스 | 안내 박스 | 메시지 한 줄 | `{colors.canvas-parchment}`, `{rounded.md}`, 패딩 32px |
| 링크 | `text-link` | 이전 화면으로 / 처음으로 | `{colors.primary}` |

## 메시지 예

| 코드 | 예 |
| --- | --- |
| 403 | "이 화면을 사용할 권한이 없어요.", "이 심사 건을 볼 권한이 없어요." |
| 404 | "분석 결과를 찾을 수 없어요." |
| 400 | "편입 전공을 다시 선택해 주세요." |
| 로그인 필요 | 화면은 `/login`으로 이동, API는 401 |
