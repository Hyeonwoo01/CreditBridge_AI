# P02 학생 홈 (내 편입 요청 · 대시보드)

| 항목 | 내용 |
| --- | --- |
| URL | `GET /student` (계정 성적표가 없으면 P26으로 303), 졸업 학점 반영 `POST /student/requests/{id}/counted`, 예전 방식 빈 요청 지우기 `POST /student/requests/{id}/delete` |
| 역할 | 학생 (입학이 확정되어 대상 대학에 소속된 계정) |
| 템플릿 | `student/index.html` |
| 기능 | 성적표의 C 이상 과목마다 자동으로 만든 요청 목록(학생은 요청을 만들지 않고 과목마다 강의계획서를 올림. 출신 대학·편입 전공은 학교가 계정에 정한 값 — 관리자가 P18 계정 CSV·P24 계정 수정에서 정함), 편입 학점 상한을 넘을 때 졸업 학점에 넣을 과목 고르기, FR-21 할 일 목록, FR-15 전체 합계(요청을 합친 예상 인정 학점·판정 확정 수·남은 학기)와 요청별 예상 인정 학점·판정 확정 수, 제출 전 서류 준비율 |

## 동작

- 과목 요청은 계정 성적표(P26)를 올리면 작업 큐가 과목 줄을 뽑은 뒤 성적 C 이상 과목마다 만든다. 같은 과목은 다시 만들지 않고, 아직 제출하지 않은 요청은 새 성적표 값(성적·학점)으로 바뀐다. 새 성적표에서 빠졌거나 C 미만이 된 과목은 강의계획서를 올리기 전이면 지운다.
- 졸업 학점 [빼기]·[다시 넣기] → `303` P02 `#total-title`.
