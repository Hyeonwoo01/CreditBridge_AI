# P02 학생 홈 (내 편입 요청 · 대시보드)

| 항목 | 내용 |
| --- | --- |
| URL | `GET /student`, 요청 만들기 `POST /student/requests`, 빈 요청 지우기 `POST /student/requests/{id}/delete` |
| 역할 | 학생 (입학이 확정되어 대상 대학에 소속된 계정) |
| 템플릿 | `student/index.html` |
| 기능 | 편입 요청 만들기(출신 대학·편입 전공은 학교가 계정에 정한 값을 보여 주기만 함 — 관리자가 P18 계정 CSV·P24 계정 수정에서 정함), 서류 없는 빈 요청 지우기, FR-21 할 일 목록, FR-15 전체 합계(요청을 합친 예상 인정 학점·판정 확정 수·남은 학기)와 요청별 예상 인정 학점·판정 확정 수, 제출 전 서류 준비율 |

| 편입 대학 | 텍스트 | 학생 소속 대학(바꿀 수 없음) | 〃 |

| 만들기 버튼 | `button-simulation-hero` | "새 요청 만들기". 출신 대학·편입 전공이 모두 있을 때만 보임. 서류를 올리지 않은 요청이 이미 있으면 새로 만들지 않고 그 요청을 연다(잘못 눌러도 빈 요청이 쌓이지 않음) | `{colors.primary}`, 18px/300, 패딩 14px 28px |

| 할 일 목록 | 헤어라인 목록(행 전체가 링크) | 아이콘 원 + 할 일 + (요청이 2건 이상이면) 어느 요청인지 + ›. 종류: 새 판정 결과 확인(→ P14 알림), 보완 자료 제출(→ 그 과목 P04), 성적표 올리기·과목 연결 확인(→ P03 `#transcript`), 강의계획서 올리기·미등록 N건(→ P03 `#upload`), 분석하지 못한 강의계획서 다시 올리기(→ P03), 학사처에 심사 요청하기(→ P03 `#submit`, 채울 서류가 없고 분석이 끝났을 때만) | 흰 배경, `{colors.hairline}` 테두리·구분선, `{rounded.lg}`, 행 패딩 14px 20px. 아이콘 원 24px: 채울 서류 "!" `{colors.surface-elective-subtle}` + `{colors.status-elective}`, 다음 단계 "→"·결과 건수 `{colors.highlight-evidence-target}` + `{colors.primary}` |

## 상태

| 상태 | 표시 |
| --- | --- |
| 소속 대학 없음 | 만들기 바 대신 파치먼트 안내: "입학이 확정된 대학에 소속된 계정만 편입 요청을 만들 수 있어요." |
| 요청 없음 | 파치먼트 빈 상태: "아직 편입 요청이 없어요. 위에서 대학을 골라 시작해 보세요." |
| 할 일 없음 | "할 일" 영역 숨김 |
| 심사 중·판정 완료 요청 | 서류 준비율 숨김. 할 일에는 보완 자료 요청만 나옴 |
| 출신 대학·편입 전공이 계정에 없음 | 만들기 버튼 대신 펄 안내: "계정에 출신 대학·편입 전공이 아직 없어요. 학사처(기관 관리자)에 등록을 요청해 주세요." (요청을 보내도 400 같은 문구) |
| 빈 요청이 이미 있는데 또 누름 | 그 요청 P03으로 이동 + 플래시 "아직 서류를 올리지 않은 요청이 있어 그 요청을 열었어요. 여기에 서류를 올려 주세요." |
| 빈 요청 지움 | P02로 돌아와 플래시 "빈 편입 요청을 지웠어요." (서류가 생긴 요청이면 빨강 "서류를 올렸거나 심사를 요청한 요청은 지울 수 없어요.") |
