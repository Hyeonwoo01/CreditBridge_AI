# P11 배정된 심사 (교수 홈)

| 항목 | 내용 |
| --- | --- |
| URL | `GET /professor`, 부재 설정 `POST /professor/away` |
| 역할 | 학과 교수 |
| 템플릿 | `professor/index.html` |
| 기능 | 배정 목록(판정 전 + 이의 신청 재판정), 최근 판정한 심사(판정을 마친 건 다시 열기), FR-19 부재 기간·대리 심사자 |

## 위치

```
[global-nav: 배정된 심사(선택) (1)]   ← 판정할 건수, P00
제목 "배정된 심사 N건" + "근거 구절 비교부터 보고 판정할 수 있어요"
┌ 배정 카드 (링크 → P12) ──────────────────────────────┐
│ 과목 코드·이름                    [추천 배지] 90%     │
│ [이의 신청 재판정] (해당 시)                          │
│ → 후보 과목 · 배정일 · (부재 교수 대리 배정 시) 안내    │
└─────────────────────────────────────────────────────┘
최근 판정한 심사 N                     누르면 판정 화면과 근거를 다시 볼 수 있어요
┌ 행 (링크 → P12) ─────────────────────────────────────┐
│ 과목 코드·이름        [판정 결과 배지] [이의 신청 재판정 → 결과] [문서 삭제로 종료] │
│ → 대상 과목 · 승인/수정/반려 · 판정일 (· 이의 신청 재판정)                         │
├─────────────────────────────────────────────────────┤
│ … 최근 20건                                           │
└─────────────────────────────────────────────────────┘
(20건 넘으면) "최근 20건만 보여요."
┌ 부재 설정 카드 ─────────────────────────────────────┐
│ 부재 일수(0이면 복귀) │ 대리 심사 교수 ▾ │ [저장]      │
└─────────────────────────────────────────────────────┘
[footer]
```

## 컴포넌트

| 영역 | 컴포넌트 | 내용 | 토큰 |
| --- | --- | --- | --- |
| 배정 카드 | `evaluation-utility-card` (링크) | 과목, 추천 배지, 커버리지(정보 부족이면 숨김), 후보, 배정일 | hover 테두리 `{colors.primary}` 40% |
| 재판정 배지 | `confidence-badge-pill` | "이의 신청 재판정" | 빨강 글자 |
| 최근 판정한 심사 | `card` 안 행 목록 (`views.professor_recent`) | 이 교수가 판정한 심사 건(재판정은 한 건으로), 최근 판정 순 20건. 행: 출신 과목, 이 교수의 판정 결과 배지, 그 뒤 다른 판정이 있으면 "이의 신청 재판정 → 지금 결과", 요청이 문서 삭제로 끝났으면 "문서 삭제로 종료" / 대상 과목(없으면 선택 인정은 "일반 선택 학점", 그 밖에는 "대상 과목 없음")·승인·수정·반려·판정일. 제목 옆 숫자는 판정한 전체 건수 | 행 구분 `{colors.divider-soft}`, hover `{colors.canvas-parchment}`, 결과 배지는 의미 색 |
| 부재 설정 | `evaluation-utility-card` 폼 | 일수(0~120), 같은 학과 동료 select, [저장] | 버튼 `button-secondary-pill`, 입력 44px |

## 상태

| 상태 | 표시 |
| --- | --- |
| 배정 없음 | 파치먼트 "배정된 심사가 없어요." |
| 판정한 심사 없음 | 파치먼트 "아직 판정한 심사가 없어요." |
| 부재 저장 | 플래시 "진행 중인 N건을 대리 심사자에게 넘겼어요" + 대리 심사자·심사관 알림 |
| 복귀 | 플래시 "복귀로 표시했어요." |
