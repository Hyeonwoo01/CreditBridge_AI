# P20 비밀번호 찾기·재설정

| 항목 | 내용 |
| --- | --- |
| URL | `GET·POST /account/forgot`, `GET /account/reset?token=…`, `POST /account/reset` |
| 역할 | 비로그인 (로그인 화면의 "비밀번호를 잊으셨나요?") |
| 템플릿 | `account/forgot.html`, `account/reset.html` |
| 기능 | 메일 재설정·설정 링크(한 번만 사용, 30분 또는 72시간). 메일 발송이 설정되지 않았으면 기관 관리자에게 요청하도록 안내(관리자는 P18에서 재발급) |

## 위치

```
비밀번호 찾기 (/account/forgot)              새 비밀번호 정하기 (/account/reset)
  비밀번호를 잊으셨나요?                        새 비밀번호 정하기
  메일 O: 설명 + [이메일] [재설정 링크 받기]      유효: [새 비밀번호] [확인] [비밀번호 바꾸기]
  메일 X: "소속 기관 관리자에게 요청" 안내       무효: 앰버 "만료됐거나 이미 사용됐어요"
  (요청 후) "등록된 이메일이면 보냈어요"              + [재설정 링크 다시 받기]
  로그인으로 돌아가기                            로그인으로 돌아가기
```

## 컴포넌트

| 영역 | 컴포넌트 | 내용 | 토큰 |
| --- | --- | --- | --- |
| 이메일 폼 | `evaluation-utility-card` | 이메일 + `button-primary` "재설정 링크 받기" (메일 발송 설정이 있을 때만) | |
| 요청 결과 | 안내 상자 | 등록 여부와 상관없이 같은 문구 "등록된 이메일이면 재설정 링크를 보냈어요…" | parchment 배경, 1px 헤어라인 |
| 메일 미설정 안내 | 본문 | "소속 기관 관리자에게 비밀번호 초기화를 요청해 주세요" | 강조 `{colors.ink}` |
| 새 비밀번호 폼 | `evaluation-utility-card` | 숨은 토큰 + 새 비밀번호(10자 이상)·확인 | |
| 무효 링크 | 알림 띠 + `button-primary` | "재설정 링크가 만료됐거나 이미 사용됐어요" + 다시 받기 | `{colors.surface-elective-subtle}` |

## 규칙

| 항목 | 내용 |
| --- | --- |
| 메일 | 제목 "[CreditBridge] 비밀번호 재설정", 본문에 링크와 유효 시간만(이름 없음). 알림함에 남기지 않음. 로그인 실패 10회로 초기화된 경우(P01) 자동으로 보내며, 첫 줄이 "로그인 실패가 10번 이어져 보안을 위해 … 초기화했어요"이고 "본인이 시도한 것이 아니라면 기관 관리자에게도 알려 주세요" 문구가 붙음 |
| 토큰 | 서버에 저장하지 않는 서명 값. 비밀번호 해시 지문을 넣어 비밀번호가 바뀌면 무효(한 번만 사용). 유효 시간은 용도별: 본인 요청·로그인 실패 초기화 30분, 새 계정·관리자 초기화 72시간 |
| 메일 종류 | 본인 요청 "[CreditBridge] 비밀번호 재설정" / 로그인 실패 10회 "…10번 이어져 초기화했어요" / 관리자 초기화 "기관 관리자가 … 초기화했어요" / 새 계정 "[CreditBridge] 계정이 만들어졌어요". 모두 같은 /account/reset 화면으로 연결 |
| 남용 방지 | 같은 계정은 5분에 한 번만 발송, 계정 존재 여부를 알려주지 않음 |
| 흔적 | 토큰은 메일 작업 안에서 생성(DB·작업 큐·로그에 없음), 접근 로그는 쿼리 문자열 제거, 재설정 화면은 `Cache-Control: no-store`·`Referrer-Policy: no-referrer` |
| 완료 | 로그인 화면으로 이동, 플래시 "비밀번호를 바꿨어요. 새 비밀번호로 로그인해 주세요." 다른 기기의 로그인은 끊기고, 로그인 연속 실패 횟수·잠금도 풀림 |
| 무효 링크 | `GET` 400 / 이미 쓴 토큰으로 `POST` 422 |
