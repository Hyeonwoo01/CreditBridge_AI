## 표시 조건

| 요소 | 조건 |
| --- | --- |
| 보완 제출 드롭존 | 판정 전이고 분석 완료, 그리고 (열린 보완 요청이 있음 또는 초안이면서 정보 부족·선택 인정·불인정) |
| 이의 신청 안내 | 판정이 있고 처리 중인 이의 신청이 없을 때 |
| 버전 비교 | 같은 강의계획서에 앞서 끝난 분석이 있을 때만 (첫 분석·분석 중·실패에는 없음). 학생·심사관(P06)·교수(P12) 화면 모두 같은 카드 |
| 원문 패널 | 원문이 있을 때 (삭제 요청 처리 후에는 없음) |
| 원본 파일 열기 | 원본이 있을 때만 링크. PDF는 브라우저 PDF 보기로 그 쪽이 열리고(`Content-Disposition: inline`, `Cache-Control: no-store`), 학생 원본을 열면 감사 로그 `syllabus.original_view`. 삭제 요청 처리 후·권한 없음은 404·403(P17) |
