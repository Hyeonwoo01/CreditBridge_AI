# P08 문서 삭제 요청 (심사관 처리 · 관리자 승인)

| 항목 | 내용 |
| --- | --- |
| URL | 심사관 `GET /review/privacy`, `POST /review/privacy/{id}` / 관리자 `GET /admin/privacy`, `POST /admin/privacy/{id}` |
| 역할 | 심사관(처리), 기관 관리자(승인 = 즉시 삭제) |
| 템플릿 | `privacy.html` (역할별로 제목·버튼만 다름) |
| 기능 | FR-13 삭제 요청 흐름, 처리 기한 관리 |

## 위치

```
[global-nav: 심사관 "심사 큐 (2) · 이의 신청 (1) · 삭제 요청(선택) (N) · …" / 관리자 "운영 통계 · 계정·과목 (N) · 계정 목록 · 삭제 승인(선택) (N) · …"]   ← 처리·승인할 건수
제목 "문서 삭제 요청"(심사관) / "문서 삭제 승인"(관리자) + 설명
(기한 초과가 있으면) 빨강 안내 띠 "처리 기한이 지난 요청이 N건 있어요."
┌ 표 (처리할 것 먼저, 기한 임박 순) ──────────────────────────────┐
│ 요청 #·출신 대학 │ 학생 이메일 │ 접수 │ 기한 │ 상태 │ [버튼]       │
└──────────────────────────────────────────────────────────────┘
[footer]
```

## 컴포넌트

| 영역 | 컴포넌트 | 내용 | 토큰 |
| --- | --- | --- | --- |
| 경고 띠 | 알림 띠 | 기한 초과 건수 | `{colors.surface-reject-subtle}` + `{colors.status-reject}` |
| 표 | 데이터 표 | 최소 폭 680px | 행 구분 `{colors.divider-soft}` |
| 기한 | 날짜 | 기한이 지나고 완료 전이면 "· 기한 초과" 빨강 600 | `{colors.status-reject}` |
| 상태 | 텍스트 | 요청됨 / 심사관 처리 완료 · 승인 대기 / 삭제 완료 | |
| 심사관 버튼 | `button-secondary-pill` (작게) | "처리 완료" — 요청됨일 때만 | |
| 관리자 버튼 | `button-primary` (작게) | "승인·삭제", 심사관 처리 전이면 "(심사관 처리 전)" 덧붙임. 누르면 즉시 원본·추출 텍스트·성적표 정보 삭제 | |
| 완료 | 텍스트 | "YYYY-MM-DD 삭제" | 12px muted |

## 상태

| 상태 | 표시 |
| --- | --- |
| 없음 | "삭제 요청이 없어요." |
| 접수 | 학생 요청 즉시 심사관·관리자 모두에게 알림. 메뉴 배지: 심사관 "삭제 요청" = 요청됨 건수, 관리자 "삭제 승인" = 끝나지 않은 건수(요청됨 + 심사관 처리 완료) |
| 처리 | 심사관 플래시 "처리 완료로 표시했어요", 관리자에게 알림 |
| 승인 | 관리자 플래시 "삭제를 승인했어요", 학생에게 알림. 편입 요청은 종료(closed): 학생 화면 종료 안내(P03), 심사 큐·관리자 배정 화면·교수 목록에서 빠지고 담당 교수에게 "심사가 종료됐어요" 알림. 성적표 과목 요청이면 같은 과목의 새 요청(초안)을 바로 준비해 P02 목록의 같은 자리에 남긴다(계정 성적표에 그 과목이 C 이상으로 있을 때) |

## 비고

- 판정 기록과 감사 로그는 학사 기록이라 남는다(설명 문구에 명시).
- 운영 시 확인창이 필요하면 페이지 안 확인 단계로 구현한다(브라우저 `confirm()`은 일부 환경에서 막힘).
