# P14 알림

| 항목 | 내용 |
| --- | --- |
| URL | `GET /notifications?page=` (50건씩 최신순, 열면 모두 읽음 처리), 배지 `GET /notifications/count` (HTMX 조각), 웹 푸시 `POST /notifications/push/subscribe`·`/unsubscribe` (JSON + `X-CSRF-Token`), 서비스 워커 `GET /sw.js` |
| 역할 | 로그인한 모든 사용자 |
| 템플릿 | `notifications.html` |
| 기능 | FR-19·20 화면 알림 (SMTP 설정 시 같은 내용 메일, VAPID 키 설정 시 구독한 기기에 웹 푸시) |

## 알림 종류 (메시지에 이름·학번·성적 넣지 않음)

| 대상 | 계기 |
| --- | --- |
| 교수 | 새 배정, 대리 배정, 이의 신청 재판정 배정, 교수 계정 비활성화로 넘겨받은 심사, 보완 자료 도착, **기한 알림**(판정 기한이 지난 심사·내일까지 판정할 심사) |
| 심사관 | 대리 재배정, 이의 신청 접수, 삭제 요청 접수, 보완 자료 도착, **기한 알림**(판정 기한이 지난 심사·교수 배정을 기다리는 과목·처리 기한이 다가온 삭제 요청) |
| 학생 | 보완 자료 요청, 판정·재판정 확정, 이의 신청 받아들임·기각, 삭제 완료, **기한 알림**(며칠째 답하지 않은 보완 자료 요청, 과목 코드만) |
| 관리자 | 삭제 요청 승인 대기, **기한 알림**(승인 기한이 다가온 삭제 요청) |

기한 알림은 매일 `REMINDER_HOUR_UTC`(기본 13시, UTC)에 Celery beat가 보낸다. 메시지는 "기한 알림: 판정 기한이 지난 심사 1건 · 내일까지 판정할 심사 2건"처럼 건수와 과목 코드만 담고, 같은 사람에게 같은 종류는 하루 한 번만 쌓인다(비활성 계정 제외). 누르면 교수 P11, 심사관 P05, 관리자 P08, 학생은 해당 강의계획서의 보완 자료 칸으로 간다. 메일 발송이 설정돼 있으면 같은 내용을 메일로도 보낸다.

## 웹 푸시 (FR-20)

- 같은 알림을 구독한 기기(브라우저)에 푸시로도 보낸다. 제목 "CreditBridge 알림", 본문은 알림 메시지(받는 사람 언어로 번역), 누르면 알림의 링크를 연다. 이름·학번·성적은 넣지 않는다.
- 상태 문구: 확인 중 "이 기기의 알림 설정을 확인하고 있어요…" / 받는 중 "이 기기에서 푸시 알림을 받고 있어요." / 안 받음 "이 기기에서는 아직 푸시 알림을 받지 않아요." / 차단 "브라우저 설정에서 이 사이트의 알림이 차단돼 있어요. …" / 지원 안 함 "이 브라우저에서는 푸시 알림을 쓸 수 없어요. iPhone·iPad는 Safari에서 홈 화면에 추가한 뒤 …" / 오류 "푸시 알림을 설정하지 못했어요. …"
- https 주소나 localhost에서만 동작한다. iPhone·iPad는 홈 화면에 추가한 앱(`/static/manifest.webmanifest`)으로 열어야 한다.
- 구독하기 전에 쌓인 알림, 하루가 지난 알림은 보내지 않는다. 푸시 서비스가 구독 만료(404·410)를 알리면 그 기기 구독을 지운다.
- 키 만들기: `uv run python -m scripts.generate_vapid_keys` → `.env`의 `VAPID_PUBLIC_KEY`·`VAPID_PRIVATE_KEY`.
