| 항목 | 내용 |
| --- | --- |
| URL | `GET /admin/data`, 과목 CSV `POST /admin/data/courses`, 계정 CSV `POST /admin/data/accounts`, 기준 강의계획서 `POST /admin/data/courses/{id}/reference`·빼기 `POST /admin/data/courses/{id}/reference/remove`, 출신 대학 `POST /admin/data/institutions`·지우기 `POST /admin/data/institutions/{id}/delete`, 비밀번호 초기화 `POST /admin/data/password-reset`, 계정 비활성화 `POST /admin/data/accounts/active` (`email`, `action=deactivate|reactivate`) |

## 가져오기 규칙

| 대상 | 규칙 |
| --- | --- |
| 공통 | CSV만(엑셀 "CSV UTF-8", 한국어 엑셀 기본 cp949도 읽음), 5MB, 빈 줄 건너뜀. 한 줄이라도 틀리면 아무것도 저장하지 않음. 행 번호는 머리 줄을 1행으로 센 실제 줄 번호 |
| 과목 | 필수 열 code·title·credits·department·concepts. 코드 30자, 학점 0 초과 30 이하, 파일 안 코드 중복 금지. 최대 3,000줄 |
| 계정 | 필수 열 email·name·role. 학생의 편입 전공은 과목에 있는 학과만, 출신 대학은 등록된 이름만, 교직원 행에 source_institution을 적으면 오류. 이메일 형식, 파일 안 중복 금지, 다른 기관에 있는 이메일 금지, 같은 기관에 있으면 건너뜀. 최대 2,000줄 |
| 비밀번호 전달 | 메일 O: 비밀번호를 아무도 모르는 값으로 두고 설정 링크(72시간·한 번만) 메일, 관리자에게 비밀번호를 보여 주지 않음. 메일 X: 임시 비밀번호 12자(헷갈리는 글자 0·O·1·l·I 제외), 다음 로그인 때 P19에서 바꿔야 함. 어느 쪽이든 해시만 저장, 결과 화면은 `Cache-Control: no-store`, 임시 비밀번호를 메일로 보내지 않음 |
| 감사 로그 | 계정·과목 가져오기는 건수만, 기준 강의계획서 등록·빼기(`course.reference_remove`)·출신 대학 등록·지우기(`institution.delete`, 대학 이름)·재발급·비활성화(`account.deactivate`, 넘긴·비운 심사 수)·다시 활성화(`account.reactivate`)는 대상 id만 (이름·이메일 없음) |
