# P18 계정·과목 관리 (기관 데이터 준비)

| 항목 | 내용 |
| --- | --- |
| URL | `GET /admin/data`, 과목 CSV `POST /admin/data/courses`, 계정 CSV `POST /admin/data/accounts`, 기준 강의계획서 `POST /admin/data/courses/{id}/reference`, 출신 대학 `POST /admin/data/institutions`, 비밀번호 초기화 `POST /admin/data/password-reset`, 계정 비활성화 `POST /admin/data/accounts/active` (`email`, `action=deactivate|reactivate`) |
| 역할 | 기관 관리자 (심사관·교수·학생은 403) |
| 템플릿 | `admin/data.html` (보조 바 위치 "관리자 콘솔 · 계정·과목") |
| 최대 폭 | 기본 `max-w-[1280px]` |
| 기능 | 실제 운영 준비: 과목·계정 CSV 가져오기, 과목별 기준 강의계획서, 출신 대학 등록, 임시 비밀번호 재발급, 졸업·퇴직 계정 비활성화 (기능 명세 밖) |

## 가져오기 규칙

| 대상 | 규칙 |
| --- | --- |
| 공통 | CSV만(엑셀 "CSV UTF-8", 한국어 엑셀 기본 cp949도 읽음), 5MB, 빈 줄 건너뜀. 한 줄이라도 틀리면 아무것도 저장하지 않음. 행 번호는 머리 줄을 1행으로 센 실제 줄 번호 |
| 과목 | 필수 열 code·title·credits·department·concepts. 코드 30자, 학점 0 초과 30 이하, 파일 안 코드 중복 금지. 최대 3,000줄 |
| 계정 | 필수 열 email·name·role. 학생의 편입 전공은 과목에 있는 학과만, 출신 대학은 등록된 이름만, 교직원 행에 source_institution을 적으면 오류. 이메일 형식, 파일 안 중복 금지, 다른 기관에 있는 이메일 금지, 같은 기관에 있으면 건너뜀. 최대 2,000줄 |
| 비밀번호 전달 | 메일 O: 비밀번호를 아무도 모르는 값으로 두고 설정 링크(72시간·한 번만) 메일, 관리자에게 비밀번호를 보여 주지 않음. 메일 X: 임시 비밀번호 12자(헷갈리는 글자 0·O·1·l·I 제외), 다음 로그인 때 P19에서 바꿔야 함. 어느 쪽이든 해시만 저장, 결과 화면은 `Cache-Control: no-store`, 임시 비밀번호를 메일로 보내지 않음 |
| 감사 로그 | 계정·과목 가져오기는 건수만, 기준 강의계획서·출신 대학·재발급·비활성화(`account.deactivate`, 넘긴·비운 심사 수)·다시 활성화(`account.reactivate`)는 대상 id만 (이름·이메일 없음) |

## 상태

| 상태 | 표시 |
| --- | --- |
| 과목 없음 | 표에 "아직 과목이 없어요. 위에서 과목 CSV를 먼저 가져와 주세요." |
| 과목 가져오기 성공 | 플래시 "과목 N건을 새로 만들고 N건을 고쳤어요." → `#courses` |
| 기준 강의계획서 접수 | 플래시 "{코드} 기준 강의계획서를 받았어요. 글자를 읽으면 AI 비교에 쓰여요." (작업 큐에서 텍스트 읽기) |
| 출신 대학 중복·국가 코드 오류 | 빨강 플래시 |
| 재발급 대상 없음·본인 | 빨강 플래시 "우리 기관에 그 이메일의 계정이 없어요." / "본인 비밀번호는 비밀번호 변경 화면에서 바꿔 주세요." |
| 비활성화 성공 | 플래시 "{이메일} 계정을 비활성화했어요. 로그인이 막히고 다른 기기의 로그인도 끊겼어요." + (교수) "진행 중인 심사 N건을 같은 학과 다른 교수에게 넘겼어요." / "심사 N건은 넘길 교수가 없어 심사관이 다시 배정해야 해요." 넘겨받은 교수에게 알림 → `#account-active` |
| 다시 활성화 성공 | 플래시 "{이메일} 계정을 다시 활성화했어요. 이전 비밀번호로 로그인할 수 있어요." (넘긴 심사는 돌아오지 않음) |
| 비활성화 거절 | 빨강 플래시 "우리 기관에 그 이메일의 계정이 없어요." / "본인 계정은 비활성화할 수 없어요." / "이미 비활성화된 계정이에요." / "이미 활성 상태인 계정이에요." |
