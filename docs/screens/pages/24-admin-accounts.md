# P24 계정 목록·계정 수정 (관리자)

| 항목 | 내용 |
| --- | --- |
| URL | 목록 `GET /admin/accounts?q=&role=&status=active\|inactive\|all&page=`, 수정 `GET /admin/accounts/{id}`, 저장 `POST /admin/accounts/{id}` |
| 역할 | 기관 관리자 (다른 역할은 403, 다른 기관 계정은 404) |
| 템플릿 | `admin/accounts.html`, `admin/account_edit.html` (관리자 메뉴 "계정 목록") |
| 최대 폭 | 기본 `max-w-[1280px]` |
| 기능 | 권한 매트릭스 "사용자·학과·대리자 설정": 계정 찾기, 교직원 이름·교수/심사관 학과·교수 대리 심사자 수정, 비밀번호 초기화·비활성화 바로 하기 |

## 컴포넌트

| 영역 | 컴포넌트 | 내용 | 토큰 |
| --- | --- | --- | --- |
| 검색 | 흰 카드 폼 (GET) | 이메일 일부(100자), 역할 select(전체·학생·심사관·교수·관리자), [찾기]. 상태는 칩에서 고른 값 유지 | `{colors.hairline}` 1px, `{rounded.lg}`, 입력 높이 44px |
| 상태 칩 | 필터 칩 | 활성(기본)·비활성·전체. 선택 칩은 잉크 채움 | DESIGN.md 목록 필터 칩 |
| 목록 표 | `data-table` | 이메일 / 이름(교직원만, 학생은 "–") / 역할 / 학과 / 대리 심사자 이름 / 상태 배지 / [수정] | 흰 카드, 헤더 `{colors.surface-pearl}` 12px, min-width 820px, 50건씩 |
| 상태 배지 | 배지 | 활성(초록), 첫 비밀번호 변경 대기(중립), 로그인 실패로 초기화(빨강), 비활성(중립) | 의미 색 |
| 계정 정보 폼 | 카드 폼 (POST, CSRF) | 교직원: 이름(필수, 100자). 교수: 학과 select(필수, 과목에 있는 학과명만 + 지금 값), 대리 심사자 select(같은 기관 다른 활성 교수, "이름 · 학과"). 심사관: 학과 select(선택, "없음" 가능). [저장] | 버튼 `button-primary` |
| 학생 계정 | 안내 카드 | "학생 계정은 이름·학과를 여기서 보거나 고치지 않아요" | muted |
| 비밀번호 초기화 | 카드 폼 | 이메일을 숨김 값으로 `POST /admin/data/password-reset`(P18과 같은 동작, 결과는 P18에 표시) | `button-secondary` |
| 비활성화·다시 활성화 | 카드 폼 | `POST /admin/data/accounts/active` + `next=/admin/accounts/{id}` → 처리 뒤 이 화면으로 돌아옴. 비활성화는 확인 창 | `button-secondary` |

## 상태 문구

| 상황 | 문구 |
| --- | --- |
| 저장 | "계정 정보를 저장했어요." / 바뀐 것이 없으면 "바뀐 내용이 없어요." |
| 학과 철자가 과목과 다름 | "과목에 있는 학과 이름을 골라 주세요." |
| 교수 학과를 비움 | "교수는 학과를 골라야 심사를 배정받을 수 있어요." |
| 대리 심사자가 본인·다른 기관·비활성·교수 아님 | "우리 기관의 다른 교수를 대리 심사자로 골라 주세요." |
| 검색 결과 없음 | "조건에 맞는 계정이 없어요." |
| 본인 계정 | 오른쪽 카드 대신 "본인 계정은 비밀번호 변경 화면에서 관리해요." |

## 데이터 규칙

- 역할은 바꾸지 않는다(판정·요청 기록이 역할에 묶여 있음). 역할이 바뀐 사람은 새 계정을 만들고 이전 계정을 비활성화한다.
- 학과를 바꿔도 진행 중인 배정은 그대로 둔다. 새 배정부터 바뀐 학과로 간다.
- 저장하면 감사 로그 `account.update`에 바뀐 항목 이름(`name`·`department`·`delegate`)만 남기고 값(이름)은 남기지 않는다.
- 서비스: `backend/services/accounts.py`, 조회: `user_repo.search`(이메일 일부·역할·활성 여부, 역할·이메일 순).
