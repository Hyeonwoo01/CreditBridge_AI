# P13 판정 근거 리포트

| 항목 | 내용 |
| --- | --- |
| URL | `GET /evaluations/{id}/report` |
| 역할 | 볼 권한이 있는 학생(본인)·심사관(소속 기관)·교수(배정·판정). 관리자는 403 |
| 템플릿 | `report.html` |
| 기능 | FR-10 판정 이력, FR-23 감사용 근거 리포트 |

## 위치 (위 → 아래, 한 열 문서)

```
[global-nav: 역할별 메뉴 + 숫자 배지 — 학생 "내 편입 요청 (2) · 이의 신청 (2) · 인정 사례" / 심사관 "심사 큐 (2) · 이의 신청 (1) · 삭제 요청 …" / 교수 "배정된 심사 (1)" / 관리자 "계정·과목 (N) · 삭제 승인 (N) …" (P00)]
← 판정 화면으로 / 심사 건으로 / 과목 결과로 돌아가기   (역할별, 인쇄 시 숨김)
로고(120px)
"Transfer Credit Evaluation Report" / 출신 과목 → 대상 대학 · 생성 시각
사람 판정: 결과·대상 과목·처리·판정자·시각 / 사유 / 판정 당시 AI 추천 스냅숏 / 경보 확인 여부
판정·이의 신청 경과 (재판정이 있을 때)
AI 추천: 등급·커버리지·신뢰도·후보·모델
개념별 근거 (원문 검증 완료 구절, 원문 위치 [시작–끝])
같은 과목의 과거 판정
감사 로그
[ {역할 화면}으로 돌아가기 ] [ 인쇄 / PDF 저장 ]   (인쇄 시 숨김)
[footer]
```

## 컴포넌트

| 영역 | 컴포넌트 | 내용 | 토큰 |
| --- | --- | --- | --- |
| 돌아가기 | `text-link` (위) + `button-primary` (아래) | 교수 → 판정 화면(P12), 심사관 → 심사 건(P06), 학생 → 과목 결과(P04). 어디서 들어왔든 그 역할이 이 심사 건을 보는 화면으로 | `print:hidden` |
| 메뉴 | `global-nav` 역할 메뉴 | 다른 화면과 같은 상단 메뉴와 숫자 배지(P00) | |
| 머리 | 로고 + `page-title` | 전체 로고, 영문 제목 | |
| 본문 | 문서형 섹션 | 소제목 600, 본문 14px | 그림자·카드 없음(문서 그대로) |
| 근거 | 인용 줄 | 학생: “구절” [start–end] / 기준: “구절” [start–end] | 위치 `{colors.ink-muted-48}` |
| 경보 확인 | 빨강 문구 | "과거 판정과 다른 결과임을 확인하고 확정함" | `{colors.status-reject}` |

## 비고

- 개인정보(이름·학번·성적)는 표시하지 않는다. 판정자는 교수 이름만.
- 인쇄 버튼은 두지 않는다(브라우저 인쇄 기능 사용).
