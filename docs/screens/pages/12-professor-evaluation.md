# P12 판정 화면 (교수 · 모바일 승인)

| 항목 | 내용 |
| --- | --- |
| URL | `GET /professor/evaluations/{id}`, 판정 `POST /professor/evaluations/{id}/decision`, 보완 요청 `POST /professor/evaluations/{id}/materials` |
| 역할 | 학과 교수 (본인에게 배정된 건, 또는 본인이 판정한 건 열람) |
| 템플릿 | `professor/evaluation.html` + `partials/evaluation.html`, `partials/history.html`, `partials/material_request_form.html` |
| 최대 폭 | 확장형 `max-w-[1440px]` (좌우 원문 대조 칸을 넓게). 하단 판정 바도 같은 폭 |
| 기능 | FR-09 최종 판정(선택형 사유), FR-11 일관성 경보, FR-20 모바일 승인, FR-22 보완 자료 요청, FR-23 재판정 |

## 사유 창 여는 조건 (브라우저, `app.js`)

| 판정 | 사유 영역 | 경보 영역 | 창 |
| --- | --- | --- | --- |
| 반려 | 표시 | 과거 판정 중 불인정이 아닌 결과가 있으면 표시 | 항상 열림 |
| 수정 · AI 추천과 같은 결과·같은 대상 과목 | 숨김 | 상충 시 표시 | 상충일 때만 |
| 수정 · 등급이나 직접 인정 대상 과목이 다름 | 표시 | 상충 시 표시 | 항상 열림 |
| AI 추천대로 승인 | 숨김 | 상충 시 표시 | 상충일 때만 (없으면 바로 제출) |

- "상충"은 같은 대상 과목·유사 강의계획서(유사도 80% 이상)의 과거 판정 결과가 이번 최종 결과와 다른 경우. 화면에 실린 이력으로 미리 계산하고, 최종 판단은 서버가 다시 한다.
- 창 안의 확정 버튼으로 제출할 때만 실제로 폼이 전송된다.

## 검증 규칙 (서버)

| 조건 | 결과 |
| --- | --- |
| 반려, 또는 AI 추천과 다른 판정인데 사유 없음 | 422 "사유를 하나 이상 골라야 해요" → 사유 창을 열어 둔 채 오류 표시 |
| '기타'인데 메모 없음 | 422 "'기타'를 고른 경우에는 메모를 적어 주세요." → 사유 창에 표시 |
| 정보 부족 건을 그대로 승인 | 422 "수정 또는 반려로 판정해 주세요." → 판정 카드에 표시 |
| 직접 인정인데 대상 과목 없음 | 422 → 사유 창에 표시(수정일 때) |
| 같은 출신 과목·같은 대상 과목·유사도 80% 이상 과거 판정과 결과 다름, 미확인 | 409 → 사유 창을 열고 경보 콜아웃 + 확인 체크 (확인 후 다시 제출) |
| 배정되지 않은 교수 | 403 |
| 이미 판정됨(받아들여진 이의 신청 없음) | 422 "이의 신청으로 재심사를 진행해 주세요." |

- 오류 시 입력값(판정·등급·대상 과목·사유·메모·경보 확인)을 유지한 채 같은 화면을 다시 그린다.
- 판정이 반려·수정이었거나 409이면 사유 창을 자동으로 다시 연다(`data-autoopen`). 그 밖의 오류는 판정 카드 안에 빨강 문장으로 표시한다.

## 반응형

- 모바일(834px 미만): 근거 쌍이 세로로 쌓이고, 하단 바는 항상 고정, 버튼은 작은 캡슐(높이 36px 이상).
- 사유 창은 모바일에서도 같은 창을 화면 폭 - 32px로 띄우고, 사유 목록과 메모는 창 안에서 스크롤한다.
