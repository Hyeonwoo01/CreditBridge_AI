# P26 내 성적표 (학생)

| 항목 | 내용 |
| --- | --- |
| URL | `GET /student/transcript`, 올리기·바꾸기 `POST /student/transcript` |
| 역할 | 학생 (학생 메뉴 "성적표") |
| 템플릿 | `student/transcript.html` |
| 최대 폭 | 기본 `max-w-[1280px]` |
| 기능 | FR-02 계정 성적표 한 번 올리기(처음 들어오면 P02 대신 이 화면), 과목 줄 확인(성적 C 미만은 "성적 기준 미달"), 바꿔 올리기. 과목 줄을 뽑으면 성적 C 이상 과목마다 편입 요청을 자동으로 만든다(P02) |

## 위치

```
[global-nav: 내 편입 요청 · 성적표(선택) · 이의 신청 · 인정 사례]
내 성적표
다니던 대학의 성적표를 한 번 올리면 모든 편입 요청에 함께 쓰여요. 성적이 C 미만(C- 이하)인 과목은 인정 대상이 아니에요.
(펄) 편입 요청을 만들기 전에 성적표를 먼저 올려 주세요.        ← 아직 올리지 않았을 때
┌ 올린 성적표                              [과목 3개 | 과목 정리 중 | 읽지 못함] ┐
│ 올린 날 2026-10-21 09:00 · 등록됨: L** J****                          │
│ 성적표 과목              학점·성적                  학기               │
│ Calculus I (MATH 101)    3 · A                     2023-1              │
│ Korean History (HIST 110) 3 · C- · 성적 기준 미달(빨강)   2023-2       │
└──────────────────────────────────────────────────────────┘
┌ 성적표 올리기 / 성적표 바꾸기 (dropzone) ─────────────────────┐
│ 이름·학번은 가려서 분석하고 원본은 암호화해 보관해요. PDF 또는 스캔 이미지(JPG·PNG) │
│ 새 성적표는 아직 심사를 요청하지 않은 요청에만 반영돼요. …     ← 바꿀 때만     │
│ [파일 선택] [성적표 등록]                                           │
└──────────────────────────────────────────────────────────┘
```

## 상태

| 상태 | 표시 |
| --- | --- |
| 처음(성적표 없음) | 펄 안내 + "성적표 올리기". P02에 들어오면 이 화면으로 303 |
| 처음 올림 | P02로 303 + 플래시 "성적표를 받았어요. 이제 편입 요청을 만들 수 있어요. 과목 목록은 곧 정리돼요." |
| 바꿔 올림 | 이 화면으로 303 + 플래시 "새 성적표를 받았어요. 아직 심사를 요청하지 않은 요청에 반영돼요." |
| 분석 중 | "과목 정리 중" 배지 + "과목 목록을 정리하고 있어요. 잠시 뒤 새로고침해 주세요. 그동안에도 편입 요청을 만들고 강의계획서를 올릴 수 있어요." |
| 읽지 못함 | 빨강 "읽지 못함" + "성적표를 읽지 못했어요. 글자가 잘 보이는 PDF나 사진으로 다시 올려 주세요." (AI 설정이 없으면 설정 안내) |
| 파일 형식·크기 오류 | 빨강 플래시 (강의계획서와 같은 검사) |

## 동작

- 원본은 객체 스토리지에만 두고, 이름·학번을 가린 글로 과목 줄을 뽑는다(`analysis.process_student_transcript`). 바꾸면 이전 원본은 지운다.
- 이미 심사를 요청한 요청은 제출할 때의 성적표 줄로 심사한다(바꿔도 반영하지 않음).
- 요청 문서 삭제(P08)는 그 요청의 사본만 지우고 계정 성적표는 남긴다.
