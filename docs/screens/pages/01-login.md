# P01 로그인

| 항목 | 내용 |
| --- | --- |
| URL | `GET /login`, `POST /login`, 언어 전환 `POST /lang` |
| 역할 | 비로그인 (로그인 상태로 `/`에 오면 역할 홈으로 이동) |
| 템플릿 | `login.html` |
| 기능 | 인증 후 역할별 홈: 학생 `/student`, 심사관 `/review`, 교수 `/professor`, 관리자 `/admin/stats`. 임시 비밀번호 계정은 비밀번호 변경(P19)으로 |

## 위치

```
[global-nav: 로고만]
        ┌ 전체 로고 (220px, 가운데) ┐
        │ 제목 2줄 (page-title)      │
        │ 설명 (muted)               │
        │ ┌ 로그인 카드 ───────────┐ │
        │ │ 이메일 입력             │ │
        │ │ 비밀번호 입력           │ │
        │ │ [ 로그인 ] (Action Blue)│ │
        │ └────────────────────────┘ │
        │   비밀번호를 잊으셨나요?    │
        └ 폭 420px, 가운데 정렬 ────┘
[footer]
```

## 컴포넌트

| 영역 | 컴포넌트 | 내용 | 토큰 |
| --- | --- | --- | --- |
| 로고 | 이미지 | `static/img/logo.png` (글자 포함 전체 로고) | 너비 220px |
| 제목 | `page-title` | "수강 신청 전에, 근거 있는 학점 인정 결과를" | `{typography.display-md}` 계열 28→34px/600 |
| 설명 | 본문 | 서비스 한 줄 소개 + "최종 판정은 학과 교수가 합니다" | `{colors.ink-muted-48}` |
| 폼 | `evaluation-utility-card` | 흰 카드, 1px 헤어라인, 18px 모서리, 패딩 24px | `{rounded.lg}`, `{colors.hairline}` |
| 입력 | input | 이메일(`autocomplete=username`), 비밀번호 | 높이 44px, `{rounded.md}` 11px, 포커스 `{colors.primary-focus}` 링 |
| 버튼 | `button-primary` | "로그인" 전체 폭 | `{colors.primary}`, `{rounded.pill}`, 누르면 `scale(0.95)` |
| 비밀번호 찾기 | `text-link` | 카드 아래 "비밀번호를 잊으셨나요?" → P20 | 14px `{colors.primary}` |
| 데모 계정 (공개 데모만) | 흰 카드 | `DEMO_MODE=true`일 때만. 제목 "데모 계정으로 둘러보기", 안내(비밀번호 demo1234) + 2×2 버튼 학생·학사처 심사관·학과 교수·기관 관리자 — 누르면 그 계정으로 바로 `POST /login` | `button-secondary-pill` 전체 폭 |

## 상태

| 상태 | 표시 |
| --- | --- |
| 브라우저 언어가 영어 | 처음부터 영어 화면("Sign in", "Evidence-based transfer credit, before you register"). 상단 오른쪽 "한국어" 버튼으로 바꿀 수 있고, 로그인하면 고른 언어가 계정에 저장됨(P00 화면 언어) |
| 실패 | 카드 맨 위에 "이메일 또는 비밀번호가 맞지 않아요." (`{colors.status-reject}`), 입력한 이메일 유지, HTTP 401 |
| 연속 실패 3·4번째 | 위 문구 + "N번 더 틀리면 1분 동안 로그인할 수 없어요." (401) |
| 연속 실패 5번째 | "비밀번호를 5번 틀려 1분 동안 로그인할 수 없어요. 그 뒤로도 5번 더 틀리면 비밀번호가 초기화돼요." (429) |
| 잠긴 동안 시도 | 맞는 비밀번호도 거절, "비밀번호를 5번 틀려 로그인이 잠겼어요. N초 뒤에 다시 시도해 주세요." (429) |
| 공개 데모(`DEMO_MODE`) | 위 데모 계정 카드가 보이고, 로그인 실패는 5번마다 "비밀번호를 5번 틀려 1분 동안 로그인할 수 없어요."만(비밀번호를 초기화하지 않음) |
| 연속 실패 6~9번째 | "이메일 또는 비밀번호가 맞지 않아요. N번 더 틀리면 비밀번호가 초기화돼요." (401) |
| 연속 실패 10번째·그 뒤 시도 | "로그인 실패가 10번 이어져 보안을 위해 비밀번호를 초기화했어요." + 메일 O "가입한 이메일로 보낸 링크에서 새 비밀번호를 정해 주세요." / 메일 X "기관 관리자에게 임시 비밀번호 발급을 요청해 주세요." (423). 비밀번호를 무작위 값으로 바꿔 무효화, 다른 기기 로그인 종료, 재설정 메일 자동 발송(P20) |
| 비활성화된 계정 (P18) | 비밀번호가 맞을 때만 "비활성화된 계정이에요. 다시 쓰려면 소속 기관 관리자에게 요청해 주세요." (403). 틀리면 일반 안내 "이메일 또는 비밀번호가 맞지 않아요." (401), 실패 횟수를 세지 않고 재설정 메일도 보내지 않음 |
| 없는 이메일 | 몇 번을 틀려도 "이메일 또는 비밀번호가 맞지 않아요."만 (잠그지 않음) |
| 성공 | 연속 실패 횟수 0으로 초기화 |
| CSRF 불일치 | 오류 화면(P17) 403 |
| 임시 비밀번호로 로그인 | `/account/password`(P19)로 이동 |
| 비밀번호 재설정 직후 | 플래시 "비밀번호를 바꿨어요. 새 비밀번호로 로그인해 주세요." |
| 다른 곳에서 비밀번호가 바뀐 세션 | 다음 요청 때 이 화면으로 돌아옴 |
