## 반응형

- 834px 미만(`md` 미만): 가운데 메뉴와 로그아웃을 숨기고 햄버거 버튼(`<details>`)으로 접는다. 펼치면 검정 패널에 메뉴(행 높이 48px), 이름·역할, 로그아웃.
- 834px 이상에서 메뉴가 폭보다 길면(관리자 7개, 영어 화면) 페이지 전체가 아니라 메뉴 줄 안에서만 가로로 넘긴다(스크롤 막대 숨김). 메뉴 이름은 줄바꿈하지 않고, 메뉴 간격은 16px(1280px 이상 20px).
- 보조 바는 좁은 화면에서 기관명 줄과 집계 칩 줄로 나뉘어 쌓인다.
- 모든 터치 영역 44×44px 이상.

## 공통 규칙

- 임시 비밀번호 계정은 비밀번호를 바꾸기 전까지 메뉴·알림 수·보조 바 집계를 숨기고 다른 화면은 P19로 보낸다.
- 세션에 비밀번호 해시의 짧은 지문을 넣어, 다른 곳에서 비밀번호가 바뀌면(변경·재설정·관리자 재발급·로그인 실패 10회 초기화) 이 세션은 로그인 화면으로 보낸다.
- 상태를 바꾸는 모든 POST에 `csrf_token` 숨김 필드(HTMX는 `X-CSRF-Token` 헤더).
- 화면 폭: `base.html`의 `{% block width %}`(기본 `max-w-[1280px]`)를 상단 바·보조 바·본문·푸터가 `self.width()`로 함께 쓴다. 넓은 화면은 템플릿에서 `{% block width %}max-w-[1440px]{% endblock %}`로 덮어쓴다.
- 시각은 UTC로 받고 `app.js`가 보는 사람 현지 시각으로 바꿔 표시(`<time data-format>`).
- 글꼴: `SF Pro Text`, `Pretendard Variable`(jsdelivr), 시스템 글꼴 순. 제목은 `SF Pro Display`.
