# P19 비밀번호 변경 (첫 로그인 포함)

| 항목 | 내용 |
| --- | --- |
| URL | `GET /account/password`, `POST /account/password` |
| 역할 | 로그인한 모든 사용자 (상단 바의 "이름 · 역할"을 누르면 이동) |
| 템플릿 | `account/password.html` |
| 화면 테스트 | `test_institution_data.py` 전체 |
| 기능 | 비밀번호 변경. 임시 비밀번호 계정(`users.must_change_password`)은 바꾸기 전까지 다른 화면을 쓸 수 없음 |

## 위치

```
[global-nav: 역할별 메뉴 + 숫자 배지(P00) · 이름 · 역할 · 로그아웃 — 첫 로그인 강제 변경이면 메뉴·배지·알림 숨김]
        비밀번호 변경
        (임시 비밀번호면) 앰버 안내: "관리자가 만든 임시 비밀번호로 로그인했어요…"
        ┌ 카드 ──────────────────────────┐
        │ (오류) 빨강 문장                 │
        │ 임시 비밀번호 / 현재 비밀번호     │
        │ 새 비밀번호 (10자 이상)           │
        │ 새 비밀번호 확인                  │
        │ [ 비밀번호 바꾸기 ]               │
        └────────────────────────────────┘
        (첫 로그인이면) 로그아웃 링크
        폭 480px, 가운데
[footer]
```

## 컴포넌트

| 영역 | 컴포넌트 | 내용 | 토큰 |
| --- | --- | --- | --- |
| 안내 | 알림 띠 | 첫 로그인일 때만 | `{colors.surface-elective-subtle}`, 테두리 `{colors.status-elective}` 40% |
| 폼 | `evaluation-utility-card` | 현재(임시) 비밀번호 · 새 비밀번호 · 확인. `autocomplete`는 current-password / new-password | 입력 44px |
| 버튼 | `button-primary` | 전체 폭 | |

## 동작

| 조건 | 결과 |
| --- | --- |
| 현재 비밀번호 틀림 | 422 "현재 비밀번호가 맞지 않아요." |
| 10자 미만 / 지금과 같음 / 확인 불일치 | 422 해당 문구 |
| 성공 | 역할 홈으로 이동, 플래시 "비밀번호를 바꿨어요. 다른 기기에 로그인돼 있었다면 다시 로그인해야 해요." 이 기기 로그인은 유지 |
| 임시 비밀번호로 다른 화면 접근 | 이 화면으로 303 이동(HTMX 요청은 `HX-Redirect`, API는 403). 상단 알림 수·보조 바 집계 칩은 불러오지 않음 |
| 다른 기기의 세션 | 비밀번호가 바뀌면 끊김 (세션에 넣은 비밀번호 해시 지문이 달라짐) |

## 버튼 ↔ API

엔드포인트 ID(A·S·R·F·C·M·J)는 [API 명세 2절](../../API_Spec.md#2-엔드포인트-목록). `화면 안` = 서버를 부르지 않는 버튼.

| 버튼·링크 | API |
| --- | --- |
| 비밀번호 바꾸기 | A7 `POST /account/password` |
| 로그아웃 (첫 로그인 강제 변경 중) | A4 |
