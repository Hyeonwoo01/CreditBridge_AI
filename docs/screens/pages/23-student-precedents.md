# P23 선배 인정 사례 (학생)

| 항목 | 내용 |
| --- | --- |
| URL | `GET /student/precedents?source={출신 대학 id}&q={검색어}` |
| 역할 | 학생 (대상 대학에 소속된 계정, 다른 역할은 403) |
| 템플릿 | `student/precedents.html` (학생 메뉴 "인정 사례") |
| 최대 폭 | 기본 `max-w-[1280px]` |
| 기능 | FR-26 기관 동등 과목표를 출신 대학·과목으로 검색 |

## 컴포넌트

| 영역 | 컴포넌트 | 내용 | 토큰 |
| --- | --- | --- | --- |
| 맥락 라벨·제목 | `eyebrow` + `page-title` | "Precedents", "선배 인정 사례", 출처와 공개 범위 안내 | |
| 검색 바 | 흰 카드 폼 (GET) | 다니던 대학 select(대상이 아닌 기관), 과목 검색(코드·이름 일부, 100자), [찾기] | `{colors.hairline}` 1px, `{rounded.lg}`, 입력 높이 44px, 버튼 `button-primary` |
| 결과 표 | `data-table` | 출신 과목(600) / 인정된 과목 코드 + 이름(muted), 없으면 "–" / 결과 배지 / 판정일 | 흰 카드 외곽, 헤더 `{colors.surface-pearl}` 12px, 행 구분 `{colors.divider-soft}`, 좁은 화면은 표만 가로 스크롤(min-width 560px) |
| 결과 배지 | `confidence-badge-pill` | 직접 인정(초록)·선택 인정(앰버)·불인정(빨강) | 의미 색 3쌍 |
| 안내 | fine print | 과거 기준은 참고용, 최종 판정은 학과 교수 | 12px muted |

## 데이터 규칙

- 기관 관리자·심사관이 P09에서 가져온 **동등 과목표만** 보여 준다. CreditBridge에서 다른 학생이 받은 판정은 건수로도 보여 주지 않는다(FR-12).
- 같은 출신 과목·인정 과목·결과가 여러 줄이면 한 줄로 합치고 가장 최근 판정일을 보여 준다.
- 동등 과목표의 메모(기관 내부용)는 보여 주지 않는다.
- 정렬: 출신 과목 이름순, 같은 과목이면 직접 인정 → 선택 인정 → 불인정.

## 상태

| 상태 | 표시 |
| --- | --- |
| 동등 과목표에 그 대학 과목 없음 | "동등 과목표에 아직 이 대학 과목이 없어요. 과목별 예상 결과는 강의계획서를 올려 확인해 보세요." |
| 검색 결과 없음 | ""{검색어}"에 맞는 사례가 없어요. 과목 코드만 넣어 다시 찾아보세요." |
| 소속 대학 없음 | "입학이 확정된 대학에 소속된 계정만 인정 사례를 볼 수 있어요." |
| 다른 역할 접근 | 403 |
